# Espacio de Antonio: páginas del frontend

La aplicación mínima está en `../app.py` y ya consume el servicio de Dante. Antonio puede crear páginas Streamlit en esta carpeta para separar tutor, simuladores, terminal y retos cuando estén implementados.

Mantener la interfaz dependiente de funciones de `src/`; no copiar reglas de clasificación ni simulación en los widgets. El estado de disponibilidad de cada módulo sale de `src/modules/catalog.py`.
